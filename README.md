# EDUSRC 证书礼品搜索

适用于 Chrome、Edge 等 Chromium 浏览器的 Manifest V3 扩展。无需构建、无需安装依赖。

[下载最新版本](https://github.com/zihaoc689-maker/edusrc-gift-search/releases/latest) · [v1.1.0 插件 ZIP](https://github.com/zihaoc689-maker/edusrc-gift-search/releases/download/v1.1.0/edusrc-gift-search-v1.1.0.zip)

按学校、证书名称、来源或描述搜索公开礼品，**默认包含剩余数量为 0 的证书**。支持本地缓存、断点续扫、库存筛选、单 ID 查询和 CSV 导出。

## 安装

1. 从 Release 下载并解压 `edusrc-gift-search-v1.1.0.zip`，保留整个 `edusrc-gift-search` 文件夹。
2. Chrome 地址栏打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `edusrc-gift-search` 文件夹。
4. 点击浏览器工具栏的扩展图标，打开搜索页。需要时可在扩展菜单中固定图标。

安装后请保留该文件夹。直接双击 `search.html` 不能使用扩展功能。

## 使用

- **立即验证零库存查询**：在页面下方「已有礼品 ID？」中输入 `100`，点击「查询并收录」。2026-11-01 公开页面验证：这是浙江大学漏洞报送证书，剩余数量为 0；扩展会显示实际读取到的最新值。
- **建立索引**：默认检查 ID 1–500。也可先点击「识别最新范围」，读取公开证书列表的全部分页，以最大已知 ID 加 50 为建议上限，再点击「建立 / 更新索引」。
- **索引速度**：默认启动间隔为 **0.01 秒、8 并发**；并发可选 1、2、4、8、16、32。启动间隔控制所有请求之间的最小启动间隔，并发数控制同时进行的请求上限。暂停后可修改速度，点击「继续扫描」或「重试失败项」时生效。
- **搜索**：输入学校、名称、描述、来源或 ID；空格分隔的多个关键词必须同时匹配。粘贴完整详情 URL 可精确匹配该 ID。
- **查看零库存**：「库存」默认是「全部（含零库存）」；选择「仅零库存」可单独查看已兑完的项目。
- **暂停和继续**：扫描期间保持搜索标签页打开。可以边扫描边查询；点击「暂停扫描」会保存断点。关闭标签页或浏览器后，重新打开并点击「继续扫描」。
- **更新与重试**：重新点击「建立 / 更新索引」会更新指定范围；已有其他范围的记录会保留。失败项会单独列出，点击「重试失败项」重新读取。
- **导出**：点击「导出结果 CSV」导出当前筛选命中的全部记录。

## 搜索范围与数据

扩展读取 `https://src.sjtu.edu.cn/gift/<id>/` 的公开详情，逐个建立索引，因此不依赖列表是否展示零库存礼品。

搜索结果只覆盖已经收录的详情。自动识别范围根据公开列表推测，无法证明更大的 ID 中没有未展示的证书；如果已知更大的礼品 ID，可扩大结束 ID 或单独收录。单次最多检查 5000 个 ID，有效 ID 范围为 1–100000。

公开详情返回 404/410 时会跳过，该 ID 的旧缓存记录也会移除。无法公开访问、已删除或需验证的页面无法凭空恢复。网络错误和解析错误会记录为失败项，不会被当成零库存。遇到 401/403/429 或连续三次读取失败时暂停；429 会遵守服务器冷却时间。

默认每 0.01 秒最多启动一个新请求，同时最多 8 个请求；可调整至 32 并发。单请求超时 15 秒。实际速度取决于并发上限、网络延迟、浏览器调度和网站响应，不承诺每秒固定完成数量。扫描由搜索标签页执行，浏览器休眠或冻结该标签页可能延缓扫描。

并发响应即使乱序返回，也会保存已完成的 ID 和最早未完成的断点；继续扫描时跳过已完成项，重试不会重复增加已检查进度。遇到 401/403/429 时停止派发并取消其余在途请求，遵守冷却时间。

从 1.0 升级：将新版文件覆盖原扩展目录，在浏览器扩展管理页点击该扩展的「重新加载」，再重新打开搜索页。索引和断点会保留，首次升级自动切换到 0.01 秒、8 并发。

库存为上次检查值，以官网详情为准。证书类型按名称是否包含「证书」判断；取消「只看证书」可搜索其他礼品。

## 权限与隐私

仅申请本地存储权限和 `https://src.sjtu.edu.cn/` 域名访问权限；请求代码只访问该域名下的礼品列表和详情路径。

不发送登录 Cookie，不执行兑换，不注入官网页面，无第三方服务或遥测。索引保存在当前浏览器配置的扩展本地存储中，卸载扩展会清除它。不同浏览器和配置不自动同步。

## 开发与验证

- `manifest.json`：扩展入口、权限和内容安全策略。
- `background.js`：点击图标时打开或切换到搜索标签页。
- `app.js` / `search.html` / `styles.css`：索引控制与搜索界面。
- `parser.js`：按真实页面的字段标签解析详情和分页。
- `scanner.js`：全局节奏控制、并发请求、乱序断点保存、中止和限流处理。
- `core.js`：搜索、校验、排序和 CSV 导出。

无需运行 Node 即可安装。开发测试可用 Node 20+ 在本文件夹执行 `npm test`，无依赖。测试覆盖零库存、筛选、CSV、404、429、并发上限、启动间隔、乱序断点、暂停、失败重试和保存顺序。浏览器界面使用真实页面 HTML 与模拟的扩展存储/网络验证；未在用户浏览器中安装扩展。

页面结构参考：[公开礼品列表](https://src.sjtu.edu.cn/gift/)、[浙江大学证书详情](https://src.sjtu.edu.cn/gift/100/)。如官网更改字段结构，扩展会显示解析失败，需要更新 `parser.js`。
